DEINONYCHUS WEBSITE — FIRST HOMEPAGE DRAFT

Copy index.html, style.css, and script.js into your existing
~/Desktop/deinonychus-website folder, replacing the three empty files.
Keep your existing .git directory. The images directory is ready for photos.

Preview:
cd ~/Desktop/deinonychus-website
python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000
Stop the preview with Ctrl+C.

index.html = content and page structure
style.css = colors, spacing, typography, and responsive layout
script.js = mobile menu and footer year

This is a single-page layout draft. Navigation goes to sections on the page.
All imagery and contact details are clearly marked placeholders.
Review organization naming and public copy before publishing.
No external fonts, libraries, build tools, or backend are required.
Change the color variables at the top of style.css to explore a new palette.
Replace placeholder divs with img elements when photos are ready.
